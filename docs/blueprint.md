# **App Name**: Skill Forge

## Core Features:

- Project Submission: Project proposal submission form with fields for project description, team members, roles, and planned contributions.
- Project Showcase: A project showcase page displaying submitted projects with details, team member information, and a progress tracker.
- AI Project Suggestion: AI-powered suggestion tool to generate relevant project ideas and technologies to learn based on user interests.
- Personal Dashboards: Personalized dashboards for team members to track their individual progress, contributions, and skills gained.
- Admin Dashboard: Admin dashboard for managing projects, user roles, and system configurations.
- Notifications: Automated reminders and notifications for project milestones, deadlines, and updates.

## Style Guidelines:

- Primary color: Strong teal (#26A69A) for trustworthiness and innovation.
- Background color: Light grey (#F0F0F0) to ensure readability and reduce distractions.
- Accent color: Deep orange (#FF7043) for key actions and important information.
- Clean and modern sans-serif fonts for readability and a professional feel.
- Consistent and professional icon set for easy navigation and feature identification.
- Use a clear and structured layout to make important functionality immediately visible.
